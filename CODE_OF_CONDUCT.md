# Code Of Conduct

## Our Standard

We want TidyUp to be a calm, respectful project for first-time contributors and experienced maintainers alike.

Expected behavior:

- be respectful
- assume good intent
- give specific technical feedback
- prioritize user safety over ego
- welcome beginner questions

Unacceptable behavior:

- harassment
- insults or personal attacks
- deliberate intimidation
- bad-faith security disclosures meant to embarrass others

## Enforcement

Project maintainers may edit, remove, or reject contributions that violate this standard.
