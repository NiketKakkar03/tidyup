# Governance

TidyUp is currently maintainer-led.

## Decision Making

Maintainers make final calls on:

- scope changes
- safety guarantees
- release timing
- public API stability

## MVP Bias

The project deliberately favors a small, auditable MVP over feature breadth.

Changes that expand scope beyond the `v0.1.0` promise should usually wait until the release checklist is complete.

## Contribution Areas

Community help is especially useful in:

- cross-platform testing
- CLI wording and user guidance
- documentation
- release packaging
- rule-pack examples
