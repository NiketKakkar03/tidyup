# Release Notes `v0.1.1`

TidyUp `v0.1.1` is a small presentation fix for the macOS MVP.

Human-readable `scan` results now number multiple files sequentially instead
of displaying `1` for every entry. File planning, safety checks, apply,
history, and undo behavior are unchanged.

Downloads remain available separately for Apple Silicon and Intel Macs. Each
archive includes a no-admin installer, an uninstaller, the MIT License, and a
SHA-256 checksum. The binaries remain intentionally unsigned and not
Apple-notarized.
