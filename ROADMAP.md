# Roadmap

## `v0.1.0` MVP

Goal:

- a first-time user can safely organize one folder and undo the result without knowing shell commands

Included:

- direct-child scanning
- deterministic extension-based rules
- previewable plans
- safe same-root moves
- SQLite-backed history
- guarded undo
- human and JSON CLI output

Explicitly out of scope:

- recursive cleanup
- deletion
- duplicate cleanup
- cross-volume copy-and-delete flows
- automatic renaming to resolve collisions
- background agents
- desktop GUI
- cloud or AI classification

## After `v0.1.0`

Possible post-MVP areas:

- richer built-in rules
- improved install story
- broader artifact distribution
- more polished terminal UX
- stronger Windows/macOS coverage for awkward filesystem cases
