# Changelog

## `v0.1.0` - August 19, 2026

Initial MVP release candidate.

Highlights:

- read-only `scan` and `plan`
- interactive `apply`
- SQLite-backed operation history
- `history` and `history show`
- guarded `undo`
- safer terminal summaries and project-folder warnings

Known limitations:

- only direct-child files are organized
- extension-based rules only
- no recursive organization
- no GUI installer yet
